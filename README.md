\# Swag Labs Web Application - Manual Testing Project



\## Project Overview



This project contains manual testing activities performed on the Swag Labs web application.



The purpose of this project is to verify application functionality, evaluate usability, identify defects, and document unexpected behaviors through structured manual testing and exploratory testing.



Application Tested:

\- Swag Labs Web Application



Testing Type:

\- Manual Functional Testing

\- Exploratory Testing





\## Testing Objective



The objectives of this testing project were:



\- Verify that the main application functionalities work as expected.

\- Validate user flows from login until checkout completion.

\- Identify functional defects and usability issues.

\- Explore application behavior using special test accounts.

\- Document discovered defects using proper bug reports.

\- Provide an overall testing summary and recommendations.
